# Pixel Academy

Next.js landing page for Pixel Academy.

## Requirements

- Node.js 24 LTS or newer
- npm

## Setup

```powershell
npm install
npm run dev
```

Open:

```txt
http://localhost:3000
```

## Checks

```powershell
npm run typecheck
npm run lint
npm run build
```

The project is configured for static export. Production build output is generated in `out/` and is intentionally not committed.
